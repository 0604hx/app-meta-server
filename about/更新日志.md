### spring boot 4 升级问题记录

#### 不支持 undertow
> Spring Boot 4 要求 Servlet 6.1，而 Undertow 当时不兼容 Servlet 6.1，因此 Spring Boot 4 删除了 Undertow 支持，包括 Undertow Starter。

切换到 tomcat 依赖。

#### CacheProperties 不存在

```java
import org.springframework.boot.autoconfigure.cache.CacheProperties;
// 改成
import org.springframework.boot.cache.autoconfigure.CacheProperties;
```

#### org.springframework.boot.web.client 不存在
> 因为整个 Web Client 模块已经从 spring-boot-autoconfigure 中拆出来了

添加依赖：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-restclient</artifactId>
</dependency>
```

引入`import org.springframework.boot.restclient.RestTemplateBuilder;`

### HttpHeaders 不实现 Map 接口
> 要对 Headers 处理的代码进行修复

### Property 'sqlSessionFactory' or 'sqlSessionTemplate' are required
> 这是由于 mybatis-plus 版本过低，升级到最新的 3.5.16

```xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot4-starter</artifactId>
    <version>${version.mybatis-plus}</version>
</dependency>
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-jsqlparser</artifactId>
    <version>${version.mybatis-plus}</version>
</dependency>
```

### io.jsonwebtoken.jackson.io.JacksonDeserializer Unable to get public no-arg constructor
> 原因是确实 jackson-databind 依赖，原来 springboot 3.x 是自带了😂

```xml
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-jackson</artifactId>
    <version>${jjwt.version}</version>
    <scope>runtime</scope>
    <exclusions>
        <exclusion>
            <groupId>com.fasterxml.jackson.core</groupId>
            <artifactId>jackson-databind</artifactId>
        </exclusion>
    </exclusions>
</dependency>
```

上面的依赖在 spring boot 3 下正常，到了 4.x 需要将 jackson-databind 引入
